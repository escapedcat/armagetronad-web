# M0 — Dedicated Server on WASM/Node Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The real Armagetron dedicated server, compiled to WebAssembly, boots under Node.js, parses a map, and reaches its steady serving state — proving toolchain + libxml2 + C++ portability before any graphics work.

**Architecture:** A hand-written `web/Makefile` drives `em++` over the six engine library dirs (`src/{tools,network,engine,render,ui,tron}`) exactly as `src/Makefile.am` does for native dedicated builds — same file set, `DEDICATED` defined via a hand-written `src/emscripten/config.h` (precedent: `src/win32/config.h`). libxml2 2.12.x is built to a static wasm library once via `emconfigure`. The output runs under Node with `NODERAWFS` (direct access to the real filesystem — no asset packaging needed for M0).

**Tech Stack:** Emscripten SDK (latest, version pinned at install time), Node ≥ 22 (v22.12.0 present), GNU make, libxml2 2.12.x.

## Global Constraints

- Every change to an existing source file must be `#ifdef __EMSCRIPTEN__`-guarded; the `#else` branch keeps the original code byte-for-byte. Native builds stay untouched.
- New files ONLY under `src/emscripten/`, `web/`, `deps/`, `docs/`.
- Network code must keep compiling unchanged — guards may bypass at runtime, never delete or stub out protocol logic.
- Compiler flags: `-std=gnu++14 -O2` (from PLAN.md strategy table).
- NEVER define: `HAVE_LIBPTHREAD`, `HAVE_LIBZTHREAD`, `TOP_SOURCE_DIR`, platform macros (`WIN32`, `MACOSX`, `linux`), curl/krawall/SDL macros (M0 is the dedicated variant).
- `main` is frozen — no merges from the `upstream` remote.
- `~/data/src/armagetronad` (outside this repo) is a read-only reference snapshot. Never modify it.
- Work happens in this worktree (`.worktrees/m0-dedicated-server`, branch `m0-dedicated-server`). Commit after every green step; committer identity is already configured (escapedcat).
- There is no automated test suite in this repo. "Tests" in this plan are build/run verifications with expected output stated per step. Where the expected output is written as *approximate*, success = reaching the described state, not matching strings exactly.

## Known landmines (discovered during planning — do not rediscover)

- `src/network/master.cpp` contains its own `main()` (the master-server binary). It MUST be excluded from the wildcard source list or linking fails with duplicate `main` (the real one is `src/tron/gArmagetron.cpp:620`).
- Sources include the config header as `#include "config.h"` (e.g. `src/tools/tMemManager.h:31`) — our header must be found first via `-I src/emscripten` BEFORE any other include dir.
- `src/defs.h` (at `src/`, not `src/tools/`) provides float-math fallbacks under `#ifndef HAVE_SINF` etc. — if the `HAVE_*F` macros are missing, those fallbacks collide with musl's own declarations. `config.h` must define all nine: `ATAN2F COSF EXPF FABSF FLOORF LOGF SINF SQRTF TANF`.
- `#include "defs.h"` resolves relative to `src/` — the Makefile needs `-iquote src` (native builds compile with `srcdir = src`, getting this for free).
- `nTrueVersion.h` is included by `src/network/nNetwork.cpp:97` and `src/render/rConsoleCout.cpp:57`; natively it's generated by the version machinery. We hand-write it.
- Emscripten's `sleep`/`usleep` without Asyncify busy-waits under Node with a console warning — acceptable for M0 (the server is a validation artifact; Asyncify arrives in M1).
- Socket creation may fail or no-op under Node — per PLAN.md this must fail *gracefully* (server keeps running). A crash on socket setup is a bug to fix with a guard; a logged error is success.

### Task 2: libxml2 built for wasm

**Files:**

**Interfaces:**
- Produces: `deps/build/libxml2-install/lib/libxml2.a` and headers under `deps/build/libxml2-install/include/libxml2/`, HTTP module enabled. The Makefile (Task 4) consumes exactly these paths.

- [ ] **Step 1: Write the build script**

Create `deps/build-libxml2.sh`:

```bash
#!/usr/bin/env bash
# Builds a static wasm libxml2 for the port.
# Pinned to the 2.12 line: last with nanoHTTP, which tResourceManager.cpp
# requires at compile time (see PLAN.md strategy table). Do not bump to >=2.13.
set -euo pipefail
cd "$(dirname "$0")"

VERSION="${LIBXML2_VERSION:-2.12.10}"
SERIES="${VERSION%.*}"
BUILD="$PWD/build"
SRC="$BUILD/libxml2-$VERSION"
PREFIX="$BUILD/libxml2-install"

command -v emconfigure >/dev/null || { echo "emsdk env not sourced" >&2; exit 1; }

mkdir -p "$BUILD"
if [ ! -d "$SRC" ]; then
  curl -fL "https://download.gnome.org/sources/libxml2/$SERIES/libxml2-$VERSION.tar.xz" \
    -o "$BUILD/libxml2-$VERSION.tar.xz"
  tar -xf "$BUILD/libxml2-$VERSION.tar.xz" -C "$BUILD"
fi

cd "$SRC"
emconfigure ./configure \
  --disable-shared --enable-static \
  --without-python --without-threads --without-zlib --without-lzma \
  --without-modules --with-http \
  --host=wasm32-unknown-emscripten \
  --prefix="$PREFIX"
emmake make -j"$(sysctl -n hw.ncpu)"
emmake make install

echo "OK: $PREFIX/lib/libxml2.a"
```

Then: `chmod +x deps/build-libxml2.sh`

- [ ] **Step 1: Write config.h (dedicated variant)**

Create `src/emscripten/config.h`:

```c
/* Hand-written config for Emscripten builds — dedicated-server (M0) variant.
   Precedent: src/win32/config.h, src/config_ide.h. Native builds never see
   this file; it must be first on the include path (-I src/emscripten).
   Rules (PLAN.md): no threads, no SDL (yet), no curl/krawall, no
   TOP_SOURCE_DIR, no platform macros. */
#ifndef CONFIG_H_INCLUDED
#define CONFIG_H_INCLUDED

#ifndef __EMSCRIPTEN__
#error "src/emscripten/config.h is only for Emscripten builds"
#endif

#define DEDICATED 1

#define PACKAGE "armagetronad"
#define VERSION "0.2.9-wasm"

#define HAVE_LIBXML2 1

/* The tMemManager custom allocator predates modern toolchains; bypass it. */
#define DONTUSEMEMMANAGER 1

/* Float math: musl provides all of these. Without them, the fallbacks in
   src/defs.h collide with musl's own declarations. */
#define HAVE_ATAN2F 1
#define HAVE_COSF 1
#define HAVE_EXPF 1
#define HAVE_FABSF 1
#define HAVE_FLOORF 1
#define HAVE_LOGF 1
#define HAVE_SINF 1
#define HAVE_SQRTF 1
#define HAVE_TANF 1

/* Provided by Emscripten's musl/headers. */
#define HAVE_ISBLANK 1
#define HAVE_SELECT 1
#define HAVE_SOCKLEN_T 1
#define HAVE_WMEMSET 1
#define HAVE_UNISTD_H 1
#define HAVE_STDINT_H 1
#define HAVE_INTTYPES_H 1
#define HAVE_STDLIB_H 1
#define HAVE_STRING_H 1
#define HAVE_STRINGS_H 1
#define HAVE_SYS_STAT_H 1
#define HAVE_SYS_TYPES_H 1
#define HAVE_MEMORY_H 1

#endif /* CONFIG_H_INCLUDED */
```

- [ ] **Step 1: Write the Makefile**

Create `web/Makefile` (run from the repo root: `make -f web/Makefile`):

```makefile
# Hand-written Emscripten build (see PLAN.md: autotools is NOT used for wasm).
# M0: dedicated server for Node. Usage, from the repo root:
#     source deps/emsdk/emsdk_env.sh
#     make -f web/Makefile dedicated -j8
EMXX      := em++
LIBXML2   := deps/build/libxml2-install

# -I src/emscripten MUST come first: it serves the hand-written config.h.
# -iquote list mirrors the per-library dirs in src/Makefile.am; -iquote src
# is what native builds get implicitly from compiling inside src/.
INCLUDES  := -I src/emscripten \
             -I $(LIBXML2)/include/libxml2 \
             -iquote src \
             -iquote src/tools -iquote src/network -iquote src/render \
             -iquote src/ui -iquote src/engine -iquote src/tron \
             -iquote src/thirdparty/binreloc \
             -iquote src/thirdparty/particles

CXXFLAGS  := -std=gnu++14 -O2 $(INCLUDES)

# src/network/master.cpp has its own main() (master-server binary) — exclude.
EXCLUDES  := src/network/master.cpp
SRCS      := $(filter-out $(EXCLUDES), \
               $(wildcard src/tools/*.cpp) $(wildcard src/network/*.cpp) \
               $(wildcard src/engine/*.cpp) $(wildcard src/render/*.cpp) \
               $(wildcard src/ui/*.cpp)    $(wildcard src/tron/*.cpp))
OBJDIR    := web/build-m0
OBJS      := $(SRCS:src/%.cpp=$(OBJDIR)/%.o)

LDFLAGS   := -sENVIRONMENT=node -sNODERAWFS=1 -sEXIT_RUNTIME=1 \
             -sALLOW_MEMORY_GROWTH=1

web/dist-m0/armagetronad-dedicated.js: $(OBJS) $(LIBXML2)/lib/libxml2.a
	@mkdir -p web/dist-m0
	$(EMXX) $(OBJS) $(LIBXML2)/lib/libxml2.a $(LDFLAGS) -o $@

$(OBJDIR)/%.o: src/%.cpp
	@mkdir -p $(dir $@)
	$(EMXX) $(CXXFLAGS) -c $< -o $@

.PHONY: dedicated clean
dedicated: web/dist-m0/armagetronad-dedicated.js
clean:
	rm -rf $(OBJDIR) web/dist-m0
```

- [ ] **Step 3: The compile grind — iterate to zero errors**

```bash
source deps/emsdk/emsdk_env.sh
make -f web/Makefile dedicated -j8 2>&1 | tail -40
```

This WILL produce errors — that is M0 doing its job. Loop: take the FIRST error, classify, fix, re-run. Classification rules:

1. **Missing `HAVE_*` macro / config assumption** → fix in `src/emscripten/config.h` only.
2. **Include-path problem** (header not found that exists in-tree) → fix the `-iquote`/`-I` list in `web/Makefile` only.
3. **Genuine portability error in a source file** (POSIX API missing under Emscripten, platform `#include`, etc.) → minimal `#ifdef __EMSCRIPTEN__` guard at the error site, original code preserved in the `#else`. Worked example of the required style:

```cpp
#ifdef __EMSCRIPTEN__
    // wasm: no clearenv() in this environment; the variable is absent anyway.
    ret = 0;
#else
    ret = clearenv();
#endif
```

4. **Error inside network code** → guards may skip a *call site* at runtime, but the functions themselves keep compiling (Global Constraint). If a network TU won't compile at all, stop and reconsider — that contradicts the plan's research and deserves a note in the commit message.

Never fix by deleting code, disabling warnings wholesale, or excluding additional files (the EXCLUDES list grows only for additional `main()`s/test harnesses, with a comment).
